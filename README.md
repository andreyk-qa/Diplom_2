# Автоматизированные тесты UI для "Stellar Burgers"

Данный проект содержит набор автоматизированных UI тестов, разработанных с использованием `pytest` и `Selenium WebDriver`, для проверки основного функционала веб-приложения "Stellar Burgers".

## Технологии

| Технология/Библиотека | Назначение |
| :--- | :--- |
| Python 3.8+ | Основной язык программирования |
| `pytest` | Фреймворк для написания и запуска тестов |
| `Selenium WebDriver 4.15.0` | Автоматизация взаимодействия с браузером |
| `allure-pytest` | Для генерации подробных отчетов о тестировании |
| `requests` | Для работы с API (регистрация пользователей) |
| Page Object Pattern | Паттерн проектирования тестов |

## Архитектура проекта

Проект организован с использованием паттерна Page Object Model
### Ключевые файлы:

| Файл | Назначение |
| :--- | :--- |
| `data.py` | Содержит константы: базовые URL-адреса, пути к API эндпоинтам |
| `conftest.py` | Содержит фикстуры Pytest для настройки браузеров, создания тестовых пользователей |
| `helpers.py` | Вспомогательные функции: генерация тестовых данных, работа с API |
| `base_page.py` | Базовый класс с общими методами для всех страниц |
| `*_locators.py` | Классы с локаторами элементов для соответствующих страниц |
| `*_page.py` | Page Object классы с методами для взаимодействия со страницами |

## Описание тестов

### Основная функциональность

**Файл:** `tests/test_main_functionality.py`

| Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- |
| `test_navigate_to_constructor` | Переход по клику на "Конструктор" | Успешный переход на страницу конструктора |
| `test_navigate_to_order_feed` | Переход по клику на "Лента Заказов" | Успешный переход на страницу ленты заказов |
| `test_ingredient_details_displayed_on_click` | Отображение деталей ингредиента при клике | Появление всплывающего окна с деталями |
| `test_ingredient_details_closed_on_click` | Закрытие всплывающего окна с деталями ингредиента | Окно с деталями успешно закрывается |
| `test_ingredient_counter_increases_when_added_to_constructor` | Увеличение счетчика ингредиента при добавлении в конструктор | Счетчик увеличивается с 0 до 2 |

### Лента заказов

**Файл:** `tests/test_order_feed_section.py`

| Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- |
| `test_total_orders_counter_increases_after_order_creation` | Увеличение счетчика "Выполнено за все время" | Счетчик увеличивается после создания заказа |
| `test_today_orders_counter_increases_after_order_creation` | Увеличение счетчика "Выполнено за сегодня" | Счетчик увеличивается после создания заказа |
| `test_order_appears_in_progress_section` | Появление номера заказа в разделе "В работе" | Номер заказа отображается в списке "В работе" |

## Поддерживаемые браузеры

- ✅ **Google Chrome** (браузер по умолчанию)
- ✅ **Mozilla Firefox**

## 1. Запуск тестов в Chrome (по умолчанию)
pytest --alluredir=allure-results

## 2. Запуск тестов в Firefox
pytest --browser=firefox --alluredir=allure-results
