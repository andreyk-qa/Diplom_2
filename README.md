# Автоматизированные тесты для API "Stellar Burgers"

## Описание тестов

Тесты используют декораторы `allure` для формирования структурированных отчетов.

### Тесты Пользователей

Проверяют эндпоинт `/api/auth/register` (создание пользователя).

| Файл | Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| `test_create_user.py` | `test_successful_creation_user` | Создание пользователя с корректными данными. | Код 200, `{'success': True}`. |
| `test_create_user.py` | `test_repeated_creation_user` | Попытка повторного создания пользователя с теми же данными. | Код 403, сообщение 'User already exists'. |
| `test_create_user.py` | `test_creation_user_without_required_fields` | Создание пользователя без обязательных полей (`email`, `password` или `name`). | Код 403, сообщение 'Email, password and name are required fields'. |

### Тесты Авторизации

Проверяют эндпоинт `/api/auth/login` (авторизация пользователя).

| Файл | Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| `test_login_user.py` | `test_successful_authorization_user` | Успешная авторизация пользователя. | Код 200, тело содержит `{'success': True}`. |
| `test_login_user.py` | `test_authorization_user_with_wrong_required_fields` | Авторизация с неверным email или паролем. | Код 401, сообщение 'email or password are incorrect'. |

### Тесты Заказов

Проверяют эндпоинт `/api/orders` (создание заказа).

| Файл | Тест | Описание | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| `test_create_order.py` | `test_order_creation` | Создание заказа авторизованным пользователем с ингредиентами. | Код 200, `{'success': True}`, проверка всех ингредиентов в ответе. |
| `test_create_order.py` | `test_order_creation_without_authorization` | **(Пропущен)** Создание заказа без авторизации. | Ожидается 401, `{'success': false}`. **Примечание:** Тест пропущен (`@pytest.mark.skip`) из-за найденного бага. |
| `test_create_order.py` | `test_order_creation_without_ingredients` | Создание заказа без ингредиентов. | Код 400, сообщение 'Ingredient ids must be provided'. |
| `test_create_order.py` | `test_order_creation_with_incorrect_hash_ingredients` | **(Пропущен)** Создание заказа с неверными хешами ингредиентов. | Ожидается 500. **Примечание:** Тест пропущен (`@pytest.mark.skip`) из-за найденного бага. |

## Обнаруженные баги

### ❗ Критичные проблемы:

#### **Баг #1: Создание заказа без авторизации**
- **Эндпоинт:** `POST /api/orders`
- **Ожидаемое поведение:** 401 Unauthorized
- **Фактическое поведение:** 200 OK (заказ создается)
- **Статус:** 🔴 Критичный
- **Тест:** Пропущен (`@pytest.mark.skip`)

#### **Баг #2: Неверный код ответа для невалидных хешей**
- **Эндпоинт:** `POST /api/orders` 
- **Ожидаемое поведение:** 500 Internal Server Error
- **Фактическое поведение:** 400 Bad Request
- **Статус:** 🟡 Средний
- **Тест:** Пропущен (`@pytest.mark.skip`)
